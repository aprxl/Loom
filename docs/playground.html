a scrap of cloth to practise on

Playground

Write any Loom program and run it, right here: the compiler and Treadle run in your browser.

playground_start.loomruns
use std.io.print

// This is your scrap of cloth: change anything, then press Run.
fun fib(n: u64) -> u64 = if n < 2 { n } else { fib(n - 1) + fib(n - 2) }

fun main() {
    for n in 0..12 {
        print("fib({n}) = {fib(n)}")
    }
}
Output

fib(1) = 1
fib(2) = 1
fib(3) = 2

fib(8) = 21
fib(9) = 34
fib(10) = 55
fib(11) = 89

Programs here are sandboxed: no environment variables, files live in memory and start empty, there's no terminal, and time.sleep doesn't wait. Threads run one at a time, in the reference schedule. A run stops after ten seconds.
