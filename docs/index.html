Loom

Data is the warp. Behavior is the weft. Programs are woven.

Loom is a statically typed language with no garbage collector, built around one idea: data and behavior are separate threads, and you weave them together. Today a Rust compiler turns Loom into Lua 5.4 and runs it. These pages describe what works now.
