a language for weaving programs

Loom

Data is the warp. Behavior is the weft. Programs are woven.

Loom is a statically typed language with no garbage collector. You describe data with warps, behavior with wefts, and join them with weaves. It compiles to Treadle, its own fast virtual machine, and to Lua.

Go on, change it

Every program in these docs runs right here in your browser, on the real compiler built for WebAssembly. Edit this one and press Run (or Ctrl+Enter).

landing_hello.loomruns
use std.io.print

// A warp is data.
warp Yarn: Show {
    color: String
    meters: f64
}

// A weft is behavior...
weft Knit {
    fun rows(self) -> i64
}

// ...and a weave joins the two.
weave Knit into Yarn {
    fun rows(self) -> i64 = (.meters * 4.0) as i64
}

fun main() {
    let basket = [Yarn("madder red", 12.5), Yarn("weld yellow", 3), Yarn("woad blue", 7.25)]
    for y in basket {
        print("{y.color:<12} {y.meters:>6.2} m  ->  {y.rows()} rows")
    }
    let total = basket.map(_.meters).sum()
    print("{total} meters in the basket")
}
Output
madder red    12.50 m  ->  50 rows
weld yellow    3.00 m  ->  12 rows
woad blue      7.25 m  ->  29 rows
22.75 meters in the basket
