Chapter 12

Const parameters and control flow

const parameters, uint(n), const if, const for, and target.

This page continues Compile-time code. A const parameter takes a value that's known while compiling, and the function or warp is specialized for it. const if and const for decide what code exists.

const parameters#

A const parameter must be known at compile time. Each distinct value makes its own instance of the function, and the value can appear in types: the length in [f32; n] is the parameter. A const generic parameter (const N: usize) is worked out from the arguments, here from the array's length.

cp_zeros.loomruns
use std.io.print

// `n` must be known while compiling. Each length gets its own copy of the
// function, and the length is part of the return type.
fun zeros(const n: usize) -> [f32; n] = [0.0; n]

// `N` is a generic parameter, worked out from the array's length.
fun sum[const N: usize](xs: [i32; N]) -> i32 {
    const assert(N > 0, "summing nothing")
    var total = 0
    for x in xs {
        total += x
    }
    total
}

fun main() {
    print(zeros(3))
    print(zeros(4).len())
    print(sum([1, 2, 3]))
    print(sum[2]([10, 20]))
}
Output
[0, 0, 0]
4
6
30
  • The parameter's type is an integer type or bool for now. An argument is checked against it (T0102).
  • An argument must be something the constant folder can work out: literals, constants, other const parameters, arithmetic, comparisons, and the integer methods log2, is_power_of_two, min, max and pow. Anything else is K0109.

Types from numbers#

uint(n) and int(n) are the integer types with n bits, for n from 1 to 64. u12 is uint(12). The argument must be known at compile time (K0109 if it isn't). Together with const parameters, this lets a type follow a number:

cp_types.loomruns
use std.io.print

warp Grid[const W: u8, const H: u8] {
    fun area(self) -> u16 = W as u16 * H as u16
}

fun main() {
    // `uint(n)` and `int(n)` are the integer types with `n` bits.
    let small: uint(3) = 7
    let wide: int(12) = -2048
    print("{small} {wide}")

    // Different arguments make different types.
    print(Grid[2, 5]().area())
    let g: Grid[3, 3] = Grid[3, 3]()
    print(g.area())
}
Output
7 -2048
10
9

Warps with const parameters#

A generic warp's field types are worked out again for each list of arguments, since type Idx = uint(N.log2()) can't be resolved in the template. A const assert in a warp's body runs for each instance of it, and the error names the instance.

cp_ring.loomruns
use std.io.print

// A ring buffer whose cursors are exactly as wide as its capacity needs.
// With N = 4 they are `u2`, so `+%= 1` wraps at N with no extra code.
warp Ring[T, const N: usize] {
    const assert(N.is_power_of_two(), "Ring capacity must be a power of two, got {N}")

    type Idx = uint(N.log2())
    type Len = uint(N.log2() + 1)

    slots: [?T; N] = [none; N]
    head: Idx = 0
    tail: Idx = 0
    pub(get) len: Len = 0

    /// Adds to the back. When the ring is full, the oldest item is dropped
    /// and returned.
    pub fun push(mut self, take x: T) -> ?T {
        let evicted = if .len == N { .pop() } else { none }
        .slots[.tail] = x
        .tail +%= 1
        .len += 1
        evicted
    }

    pub fun pop(mut self) -> ?T {
        if .len == 0 { return none }
        let x = .slots[.head].take()
        .head +%= 1
        .len -= 1
        x
    }
}

fun main() {
    var recent = Ring[u32, 4]()
    for n in 1u32..=6 {
        if recent.push(n) is some(old) {
            print("dropped {old}")
        }
    }
    while recent.pop() is some(n) {
        print("kept {n}")
    }
}
Output
dropped 1
dropped 2
kept 3
kept 4
kept 5
kept 6

const if#

const if cond { ... } else { ... } is decided while compiling, and the whole else if chain with it. The compiler checks, and emits, only the branch it takes. The others are parsed but never type-checked, so they can name things that don't exist on this target.

ci_basic.loomruns
use std.io.print

const DEBUG = false
const SIZES = [1, 2, 4]

/// The branch that isn't taken isn't checked, so it can name things that
/// don't exist here.
fun page_size() -> usize {
    const if target.pointer_bits == 64 {
        4096
    } else {
        8192
    }
}

fun describe[const N: usize](xs: [i32; N]) -> str {
    const if N > 2 { "long" } else { "short" }
}

fun main() {
    print(page_size())
    print("{describe([1, 2, 3])} {describe([1])}")

    const if DEBUG {
        print("debug on")
    } else if SIZES.len() == 3 {
        print("three sizes")
    }

    // `const if` is an expression too.
    let width: i32 = const if DEBUG { 64 } else { 32 }
    print(width)
}
Output
4096
long short
three sizes
32
  • The condition must be something the constant folder can work out, like a const argument: literals, constants, const parameters, target, arithmetic and comparisons. Otherwise it's K0110, or K0105 if it reads a local variable.
  • It can be an expression. Its branches then have to give a value.

const for#

const for is unrolled while compiling. Its body is checked once for each item, with the loop variable known at compile time, so each copy can use it in a type ([0u8; i + 1] above and below). It goes over a range, an array literal, a constant that holds an array, or .indexed() of one of those. It can run at most 10,000 times (K0102). break and continue can't target a const for yet (U0102).

ci_for.loomruns
use std.io.print

const SIZES = [1, 2, 4]

fun main() {
    // `const for` is unrolled while compiling: the body is written out
    // once per item, and each copy is checked on its own. `i` is a
    // constant in each copy, so it can size an array.
    const for i in 0..3 {
        const if i > 0 { print("--") }
        let zeros = [0u8; i + 1]
        print("{i}: {zeros}")
    }

    var total = 0
    const for (i, s) in SIZES.indexed() {
        total += i as i32 * 10 + s
    }
    print(total)
}
Output
0: [0]
--
1: [0, 0]
--
2: [0, 0, 0]
37

target#

target is a std.target.Target, always in scope. It has os, arch, endian and pointer_bits, and is known at compile time, so it works in const if. It describes the machine doing the build, and pointer_bits is 64 on Treadle (the Lua backend reports 63). See std.target.

ci_target.loomruns
use std.io.print

// A `const if` on `target` picks a branch while compiling.
fun separator() -> str {
    const if target.os == .Windows {
        "\\"
    } else {
        "/"
    }
}

fun main() {
    // `target` describes the machine the program is built for.
    print(target.pointer_bits)
    print(target.endian == .Little)
    print(separator().len())
}
Output
64
true
1

std.sys, and const funs that return types are not built. const parameters of other types than integers and bool aren't either. See Not supported yet.
