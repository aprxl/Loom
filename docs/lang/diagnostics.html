Diagnostic codes

Every code the compiler can report, with its one-line meaning. Generated from crates/loom_syntax/src/diag/codes.rs.

A diagnostic looks like error[K0101]: const assertion failed. The letter says which part of the compiler found it, and the digits are stable, so a code is safe to search for. Where a chapter shows the error happening, the code links to that sample, and you can run it there and poke at it.

Anything the compiler doesn't do yet fails with a U code. It never compiles it wrongly. See Not supported yet.
