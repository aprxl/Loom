Language / Values and control flow

Values and control flow

Numbers, text, if, match, loops, lambdas, and bit patterns.

Numbers

u12, i24 and u4 are ordinary types: any width from 1 to 64 bits. A uN does its arithmetic at exactly N bits, so a u12 overflows at 4096. usize and isize are 63 bits on the Lua backend. Types wider than 64 bits and f16 are not supported yet (U0102).

Each arithmetic operator says what happens on overflow:

OperatorOn overflow
+ - *unravels
+% -% *%wraps around
+| -| *|stops at the type's limit (saturates)
+? -? *?gives an optional, none on overflow

as, as%, as| and as? convert with the same four policies.

samples/values_numbers.loomruns
use std.io.print

fun main() {
    // Integers have any width up to 64 bits: `u12` and `i24` are ordinary types.
    let a: u12 = 4095
    print("{a +% 1} {a +| 1} {a +? 1:?}")      // wrap, saturate, checked

    let b: u8 = 200
    print("{b +% 100} {b +| 100} {b +? 100:?}")

    // Casts have the same three policies.
    print("{300 as% u8} {300 as| u8} {300 as? u8:?}")

    // Bits.
    let flags: u8 = 0b1010_0110
    print("{flags & 0x0F} {flags | 1} {flags ~ 0xFF} {flags >> 4} {flags.count_ones()}")

    // Integer division truncates; floats print the Rust way.
    print("{7 / 2} {-7 / 2} {7.0 / 2.0} {2.5f32 * 2.0}")
    print("{(2.0).sqrt():.4} {10.pow(3)} {(-5).abs()}")
}
Output
0 4095 none
44 255 none
44 255 none
6 167 89 10 4
3 -3 3.5 5
1.4142 1000 5
  • The only implicit conversion is lossless integer widening (u8 to u16). There is none between signed and unsigned, and none involving floats.
  • A number literal takes the type its context expects. With no context it becomes the first numeric type it meets, and otherwise i32 (or f64).
  • Integer / and % truncate. A zero divisor unravels. A shift by the type's width or more unravels.
  • Bit operators bind tighter than comparisons, so flags & MASK == 0 means what it looks like.

Text

str is a view of UTF-8 text and String owns it. A string literal converts to String wherever one is expected. Lengths and positions count bytes, and slicing a string cuts on bytes, unravelling if it lands inside a character. The tests on char and the case changes and trimming of text follow Unicode ('é'.is_alphabetic(), "straße".to_upper()); the _ascii variants look at ASCII only.

samples/values_text.loomruns
use std.io.print

fun main() {
    // `str` is a view of UTF-8 text; `String` owns it. Lengths count bytes.
    let s = "  Hello, Wörld  "
    let t = s.trim()
    print("[{t}] {t.len()} bytes, {t.char_count()} characters")
    print("{t.to_upper()} {t.to_lower()} {t.starts_with("Hello")} {t.find("W"):?}")
    print(t[0..5])                           // slicing counts bytes

    var out = String()
    for c in "a1b2c3".chars() {
        if c.is_digit() { out.push(c) }
    }
    out.push_str("!")
    print(out)

    print("a,b,,c".split(","))
    print("{"42".parse[u8]():?} {"x1".parse[i32]():?} {"300".parse[u8]():?}")
    print("300".parse[u8]() mend 0)
    print('f'.to_digit(16))
    print("ab".repeat(3))
}

Control flow

Everything is an expression: if, match and blocks all have values. match must be exhaustive (P0101), and an arm can have a guard. Loops are for, while and loop; break can carry a value, and a loop can have a label. Comparisons chain: 0 <= x < width.

samples/values_control.loomruns
use std.io.print

fun classify(n: i32) -> str = match n {
    0 => "zero"
    1..=9 => "small"
    10 | 20 | 30 => "round"
    x if x < 0 => "negative"
    _ => "big"
}

fun main() {
    for n in [0, 5, 20, -4, 99] {
        print("{n}: {classify(n)}")
    }

    // Ranges, `while`, `loop` with a value, labels.
    var total = 0
    for i in 1..=4 { total += i }
    print(total)

    var n = 27
    var steps = 0
    while n != 1 {
        n = if n % 2 == 0 { n / 2 } else { 3 * n + 1 }
        steps += 1
    }
    print("collatz: {steps}")

    let found = loop {
        steps += 1
        if steps % 7 == 0 { break steps }
    }
    print(found)

    outer: for row in 0..3 {
        for col in 0..3 {
            if col == 2 { continue outer }
            if row == 2 { break outer }
            print("{row},{col}")
        }
    }

    // Chained comparisons, tuples, indexed loops.
    let width = 10
    let x = 4
    if 0 <= x < width { print("in range") }

    for (i, name) in ["a", "b", "c"].indexed() {
        print("{i}={name}")
    }
}

Lambdas

x => x * 2 is a lambda. Its parameter types come from where it's passed, so a lambda stored in a let needs them written. A _ inside an argument makes a hole lambda: each _ is a new parameter, and the hole belongs to the innermost argument that holds it. A function's name is also a value. A lambda sees the variables around it.

samples/values_lambdas.loomruns
use std.io.print

fun apply(x: i32, f: i32 => i32) -> i32 = f(x)

fun is_even(n: i32) -> bool = n % 2 == 0

fun main() {
    // A lambda gets its parameter types from where it's passed.
    // Anywhere else, annotate them.
    let double = (x: i32) => x * 2
    print(apply(5, double))
    print(apply(5, x => x + 1))

    let xs = [1, 2, 3, 4, 5, 6]
    print(xs.filter(_ % 2 == 0))               // hole lambda: n => n % 2 == 0
    print(xs.filter(is_even).sum())            // a function's name is a value
    print(xs.indexed().map(p => "{p.0}:{p.1}").join(" "))
    print(xs.reduce(_ + _))                    // two holes, two parameters

    // A lambda sees the locals around it.
    var total = 0
    xs.each(x => total += x)
    print(total)
}

Twill patterns

A binary, octal or hex literal in a pattern can hold ? (any digit) and lowercase letters, which capture. All the bits with the same letter become one unsigned integer exactly that wide. The pattern's width must equal the value's. The compiler checks twill arms for exhaustiveness bit by bit.

samples/values_twill.loomruns
use std.io.print

// A twill pattern matches bits. Digits must match, `?` is "don't care",
// and each lowercase letter is a capture: every bit with the same letter
// forms one integer exactly that wide.
fun decode(op: u16) -> String = match op {
    0x00E0 => "clear"
    0x1nnn => "jump to {n}"                  // n: u12
    0x6xkk => "v{x} = {k}"                   // x: u4, k: u8
    0x8xy4 => "v{x} += v{y}"
    0xFx?? => "misc {x}"
    _ => "unknown"
}

fun utf8_kind(byte: u8) -> str = match byte {
    0b0???_???? => "ascii"
    0b110?_???? => "starts a 2-byte character"
    0b1110_???? => "starts a 3-byte character"
    0b10??_???? => "continuation"
    _ => "other"
}

fun main() {
    for op in [0x00E0, 0x1234, 0x6A42, 0x8AB4, 0xF107, 0x5000] {
        print("{op:04X}: {decode(op as u16)}")
    }
    for b in [0x41, 0xC3, 0xE2, 0xA9] {
        print("{b:02X}: {utf8_kind(b as u8)}")
    }

    // A twill pattern with no fixed digits can't fail, so `let` takes it.
    // The pattern is 9 bits wide, so the sum is worked out in `u9`.
    let a: u8 = 200
    let b: u8 = 100
    let 0bc_ssss_ssss = a + b
    print("carry {c}, sum {s}")
}

In hex twill patterns the digits A-F must be upper case. Lower case letters capture.
