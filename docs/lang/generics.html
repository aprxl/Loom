Language / Generics and any

Generics and any

Type parameters checked per instance, wefts as parameter types, and dynamic dispatch.

Generics

A type parameter goes in brackets, with bounds after a colon (T: Ord + Copy) or in a where clause. The compiler infers arguments where it can. To give them yourself, use brackets: largest[i32](xs), List[i32](), s.parse[u16]().

Generics are checked per instance, in the style of Zig. A generic function is type-checked once for each list of arguments it's used with, and one nobody calls isn't checked at all. An error in a generic body is reported once, with a note naming the instance it came from.

samples/generics_basic.loomruns
use std.io.print

// Generics are checked per instance: `largest` is checked once for `i32`
// and once for `str`. A function nobody calls isn't checked at all.
fn largest[T: Ord + Copy](xs: [T]) -> ?T {
    var best: ?T = none
    for x in xs {
        if best is some(b) and b >= x { continue }
        best = x
    }
    best
}

warp Pair[A, B] {
    first: A
    second: B

    fn swap(self) -> Pair[B, A] = Pair(.second, .first)
}

// A weave can be generic too.
weft Twice {
    fn twice(self) -> String
}

weave[T: Show] Twice into List[T] {
    fn twice(self) -> String = "{self}{self}"
}

// A weft used as a parameter type is an implicit generic.
fn show_all(xs: [Show]) -> String = xs.map(x => "<{x}>").join("")

fn main() {
    print(largest([3, 9, 4]))
    print(largest(["pear", "apple"]))
    print(largest[i32]([]))                  // explicit type arguments use brackets

    let p = Pair(1, "one")
    print("{p.swap():?}")

    let xs: List[i32] = [1, 2]
    print(xs.twice())
    print(show_all([1, 2, 3]))
}
Output
9
pear
none
Pair(first: "one", second: 1)
[1, 2][1, 2]
<1><2><3>
  • Generic warps (Pair[A, B]) and their methods are compiled per list of arguments too.
  • Generic weaves (weave[T: Show] Twice into List[T]) work the same way.
  • Wefts as parameter types are implicit generics. fn show_all(xs: [Show]) means fn show_all[T: Show](xs: [T]), and each use has static dispatch.
  • Value parameters (const N: usize) work too: see Const parameters.
  • Generic wefts (weft From[T]) are not supported yet (U0102).

any W

any Widget is a value of some type that weaves Widget. Calls on it go through a table at run time, and a type test (w is l: Label) recovers the concrete type. A value converts to any W where one is expected, and an any of several wefts (any (Widget + Show)) can be used as an any of fewer.

samples/generics_any.loomruns
use std.io.print

weft Widget {
    fn name(self) -> String
    fn width(self) -> u16 = 1
}

warp Label: Widget, Show {
    text: String
    fn name(self) -> String = "label '{.text}'"
    fn width(self) -> u16 = .text.len() as u16
}

warp Spacer: Widget {
    fn name(self) -> String = "spacer"
}

// Several wefts at once: a value that is both.
fn describe(w: any (Widget + Show)) -> String = "{w.name()} = {w}"

fn main() {
    // `any Widget` holds a value of some type that weaves Widget,
    // and calls go through a table at run time.
    let ui: List[any Widget] = [Label("hi"), Spacer(), Label("there")]
    var total: u16 = 0
    for w in ui {
        print(w.name())
        total += w.width()

        // A type test.
        if w is l: Label {
            print("  a label with {l.text.len()} letters")
        }
    }
    print(total)
    print(describe(Label("x")))
}
Output
label 'hi'
  a label with 2 letters
spacer
label 'there'
  a label with 5 letters
8
label 'x' = Label(text: "x")

Use a weft as a parameter type when the caller knows the type and you want static dispatch, and any when a list has to hold values of different types.
