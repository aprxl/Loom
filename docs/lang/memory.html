Chapter 8

Pointers, spools and given

Boxes on the heap, arenas that free everything at once, and values passed down implicitly.

Pointers#

^e puts a value in a box on the heap and gives a pointer to it, written ^T. A pointer owns its box: it moves like any non-Copy value, and dropping it drops the value and frees the box. That is how a type holds itself (^Tree inside Tree). p^ reads the box. Fields, methods, patterns and {p} see through a pointer, so t.value and match t { .Node(l, x, r) => ... } work on a ^Tree. A pointer in a var can be written through (p.x = 1, p^ += 1).

own_pointers.loomruns
use std.io.print

warp Tree {
    case Leaf
    case Node(left: ^Tree, value: i32, right: ^Tree)
}

fun insert(take t: ^Tree, v: i32) -> ^Tree = match t {
    .Leaf => ^Tree.Node(^Tree.Leaf, v, ^Tree.Leaf)
    .Node(l, x, r) => if v < x {
        ^Tree.Node(l.insert(v), x, r)
    } else {
        ^Tree.Node(l, x, r.insert(v))
    }
}

fun sum(t: ^Tree) -> i32 = match t {
    .Leaf => 0
    .Node(l, x, r) => l.sum() + x + r.sum()
}

fun main() {
    var t: ^Tree = ^Tree.Leaf
    for v in [5, 2, 8, 1, 9, 3] {
        t = t.insert(v)
    }
    print("sum {t.sum()}")

    var n = ^41
    n^ += 1
    print("{n^}")
}
Output
sum 28
42

A take pointer that a match takes apart hands its parts to the arms by value, so the arms can move them into a new node.

Spools#

A pointer into the heap owns its box and frees it. When many values live and die together (the nodes of a tree, a frame of a game) a spool is cheaper: spool frame = Arena(1.kib()) makes one, frame.put(v) moves a value into it, and ^e allocates in the spool a function is given. A pointer into a spool is Copy and owns nothing; frame.reset() takes every allocation back at once, and the spool ends with its scope.

^T@s is a pointer into the spool s, and fun tree() -> ^Node@sp given sp: Spool is a function that builds in whichever spool the caller gives (tree(4, given: frame)), or the heap if the call gives none. A parameter written ^Node takes a tree from any spool. A warp that holds pointers (Node) is Node@s for the spool its nodes are in.

own_spools.loomruns
use std.io.print
use std.mem.{Arena, Spool, kib}

warp Node {
    case Leaf(i32)
    case Pair(^Node, ^Node)
}

// The tree lives in whichever spool the caller gives; with none it is on the heap.
fun tree(depth: i32) -> ^Node@sp given sp: Spool {
    if depth == 0 { return ^Node.Leaf(1) }
    ^Node.Pair(tree(depth - 1), tree(depth - 1))
}

// A parameter without a region takes a tree from any spool.
fun count(n: ^Node) -> i32 = match n {
    .Leaf(k) => k
    .Pair(a, b) => count(a) + count(b)
}

fun main() {
    spool frame = Arena(1.kib())
    let t = tree(4, given: frame)
    print("{count(t)}")
    frame.reset()                       // every node goes at once
    let u = tree(3, given: frame)
    print("{count(u)}")
    print("{count(tree(5))}")           // no spool: the heap
}
Output
16
8
32

The region checker keeps pointers from outliving their spool: a value that points into a spool can't be returned out of the block the spool ends with (R0101), used after the spool was reset (R0102), or passed where a parameter names another spool (R0104). A spool can't be moved (M0107).

Text copied with .copy() goes in the spool the call is given, so an arena's tree can hold names and still go at once. A list, map or box can't be held by a warp that is in a spool yet (U0102): nothing would free it.

A pointer into a spool is Copy, so two copies see the same value: a field behind one can be written only when the warp is plain data (no text, lists or cases that own anything); otherwise it is read-only (T0107).

Pool[T](n) is a spool of n slots of one type: put takes a free slot and free gives it back, a few instructions each. It holds plain data only. SharedArena(cap) is an arena threads may allocate in, and its pointers may cross to them; a pointer into any other spool can't (R0103).

given#

A function can say what it needs from its caller with a given parameter of a weft: fun welcome(who: str) given g: Greeter. It is passed on by the call, not in the argument list: the innermost given in scope supplies it, given name = value states one from there to the end of the block, and given: x gives one to a single call. A weft marked #given_default(Type) has one when nothing is in scope (a spool's is the heap), so a program that never says given still runs. A function is checked for the type it is given, so an unused given costs nothing. Every function spells its own givens: a private one doesn't infer them from what it calls yet.

own_given.loomruns
use std.io.print

// A weft with a default: a call that is given nothing gets a `Plain`.
#given_default(Plain)
weft Greeter {
    fun greet(self) -> String
}

warp Plain: Greeter, Default {
    pub fun greet(self) -> String = "hello"
}

warp Loud: Greeter {
    name: String

    pub fun greet(self) -> String = "HELLO, {.name}!"
}

fun welcome(who: str) -> String given g: Greeter = "{g.greet()} {who}"

fun main() {
    print(welcome("ann"))          // nothing given: a Plain
    given g = Loud("ci")           // from here to the end of the block
    print(welcome("dee"))
    print(welcome("eve", given: Plain()))    // this one call
}
Output
hello ann
HELLO, ci! dee
hello eve
