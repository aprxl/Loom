the library

The standard library

Everything std gives you, module by module: 559 types, methods, functions and constants, each described by the doc comment in its source.

    Only the prelude is in scope without a use. Everything else is use std.module.name away, or written out in full: std.io.print("hi"). Names in code are links: follow Stream or List.push wherever you meet them.

    The basics

    Always nearby: the prelude, the core wefts, numbers, text, optionals and errors.

    Collections and streams

    Ways to hold many things, and lazy pipelines over them.

    std.listGrowable arrays: List[T] owns its elements and grows as you push.1 itemstd.sliceSlices: views of elements that sit next to each other, in an array or a list.1 itemstd.mapHash maps: Map[K, V] from any Hash key to a value.1 itemstd.setHash sets: Set[T] holds each Hash value at most once, remembers the order values were added, and has the usual set algebra.1 itemstd.dequeDouble-ended queues: Deque is a list you can push to and pop from at both ends, each in constant time (on average).1 itemstd.priorityPriority queues: PriorityQueue[T] always gives back its largest item first.1 itemstd.bitsetSets of small numbers: BitSet keeps one bit for each number from 0 up to its length, so a set of a thousand numbers takes 128 bytes, and asking whether a number is in it is one look at one bit.1 itemstd.iterIteration: the Iter weft (what for loops over), Stream (a lazy sequence and its many methods), Range (a..b), and Shuttle (generators and coroutines).11 items
