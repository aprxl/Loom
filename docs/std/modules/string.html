std / string

std.string

Text: str is a view of UTF-8 text, String owns its text and can grow. Lengths and positions count bytes, slicing (s[0..5]) cuts on bytes and unravels inside a character, and the case changes and tests follow Unicode. A string literal is a template: "{x}" formats x into it.

source: runtime/std/string.loomread about it in the book →
string_example.looman example to run
use std.io.print

fun main() {
    let line = "  name = Ada Lovelace  "
    if line.trim().split_once("=") is some((key, value)) {
        print("[{key.trim()}] -> [{value.trim()}]")
    }
    var s = String()
    for c in "loom".chars() { s.push(c.to_upper()) }
    s.push_str("!")
    print("{s} {s.len()} bytes, {"straße".to_upper()}")
    print("42".parse[u8]() mend 0)
}
