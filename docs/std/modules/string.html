Every from replaced with to. An empty from is found before every character and at the end: "ab".replace("", "-") is -a-b-.

fn split(self, sep: str) -> List[String]

The parts between each sep ("".split(",") is one empty part). An empty sep splits into each character, with no empty parts at the ends (unlike Rust's).
