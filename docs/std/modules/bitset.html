std / bitset

std.bitset

Sets of small numbers.

Types

warp BitSet

A set of the numbers 0..len, one bit each. Constant-time set, clear, test and toggle; count and the bulk operations work a word of 64 bits at a time.

fn new(len: usize) -> BitSet

A set of len numbers, none in it.

fn len(self) -> usize

How many numbers it can hold: they are 0 up to this.

fn set(mut self, i: usize)

Puts i in. Unravels if i >= len.

fn clear(mut self, i: usize)

Takes i out. Unravels if i >= len.

fn toggle(mut self, i: usize)

Puts i in if it is out, and out if it is in.

fn test(self, i: usize) -> bool

Whether i is in. Unravels if i >= len.

fn count(self) -> usize

How many numbers are in.

fn items(self) -> List[usize]

The numbers that are in, from the smallest.

fn intersect_with(mut self, other: BitSet)

Keeps the numbers that are also in other. The sets must be the same size.

fn union_with(mut self, other: BitSet)

Adds the numbers in other. The sets must be the same size.

fn subtract(mut self, other: BitSet)

Takes out the numbers that are in other. The sets must be the same size.
