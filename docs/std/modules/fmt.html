std / fmt

std.fmt

Formatting: Show is how a value becomes text in print and in templates ("{x}"), and Fmt is what show writes to. A warp that lists Show and writes no method gets its debug form, the one {x:?} always gives. dbg prints an expression and its value, and gives the value back.

source: runtime/std/fmt.loomread about it in the book →
fmt_example.looman example to run
use std.io.print
use std.fmt.dbg

warp Rgb(u8, u8, u8)

weave Show into Rgb {
    fun show(self, mut f: Fmt) {
        f.put("#{.0:02x}{.1:02x}{.2:02x}")
    }
}

fun main() {
    let madder = Rgb(238, 122, 95)
    print("madder is {madder}, or {madder:?} in its debug form")
    let n = dbg(6 * 7) + 1
    print(n)
}

Types

weft Show #

Something that can be written as text: print, {x} in templates.

fun show(self, mut f: Fmt) builtin #

Writes the value to f. A warp that doesn't write its own gets its debug form, less any fields shared by every case: Point(x: 3, y: 4), Word("let"), Red.

warp Fmt builtin #

Where show writes to.

fun put(mut self, x: any Show) #

Writes x the way {x} would.

Functions

fun dbg[T: Show](take x: T, at: str = "", expr: str = "") -> T #

Writes [file:line:col] expr = value to standard error and gives x back: let n = dbg(a + b) * 2.
