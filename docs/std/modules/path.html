std / path

std.path

File paths, as text. The separator is / on every system (Windows takes it too), so a program and its tests read the same everywhere. Nothing here touches the file system: see std.fs for that.

source: runtime/std/path.loom
path_example.looman example to run
use std.io.print
use std.path

fun main() {
    let p = path.join("docs/lang", "start.html")
    print(p)
    print("{path.file_name(p):?} {path.stem(p):?} {path.extension(p):?}")
    print(path.with_extension(p, "md"))
    print(path.normalize("a/./b/../c"))
}

Functions

fun join(a: str, b: str) -> String #

a and b as one path: join("src", "main.loom") is src/main.loom; an absolute b replaces a.

fun is_absolute(p: str) -> bool #

Whether the path starts at the root.

fun file_name(p: str) -> ?str #

The last part: file_name("a/b.txt") is b.txt. None for "" and /.

fun parent(p: str) -> ?str #

Everything before the last part: parent("a/b.txt") is a. None for a path with one part and for the root.

fun stem(p: str) -> ?str #

The last part without its extension: stem("a/b.tar.gz") is b.tar.

fun extension(p: str) -> ?str #

The part after the last dot of the last part: extension("a/b.txt") is txt. None when there is no dot, or the dot starts the name.

fun with_extension(p: str, ext: str) -> String #

The path with a different extension: with_extension("a/b.txt", "md") is a/b.md.

fun normalize(p: str) -> String #

The path without . parts, empty parts, and x/.. pairs: normalize("a/./b/../c") is a/c.
