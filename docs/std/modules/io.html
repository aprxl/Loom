std / io

std.io

Console input and output: print and its relatives, reading standard input, and the Writer weft. print writes to the Writer that a given names, so code that prints can be pointed at a Buffer without changing it.

source: runtime/std/io.loomread about it in the book →
io_example.looman example to run
use std.io.{print, Buffer}

fun report(n: i32) given out: std.io.Writer {
    print("report {n}")
}

fun main() {
    report(1)                      // to standard output
    let kept = {
        given out = Buffer()       // from here on, print writes into a Buffer
        report(2)
        report(3)
        out.text
    }
    print("kept: {kept:?}")
}
