std / cmp

std.cmp

Comparing: Ordering (what x.cmp(y) gives), min, max and clamp, and Reverse for sorting the other way. A type gets < and friends by weaving Ord; see std.ops.

source: runtime/std/cmp.loomread about it in the book →
cmp_example.looman example to run
use std.io.print

warp Racer: Show {
    name: String
    time: u32
}

fun main() {
    var racers = [Racer("Ada", 52), Racer("Grace", 48), Racer("Alan", 52)]
    racers.sort_by((a, b) => a.time.cmp(b.time).then(a.name.cmp(b.name)) == .Less)
    print(racers.map(_.name.copy()))
    print("{min(3, 7)} {max("warp", "weft")} {clamp(15, 0, 10)}")
}

Types

warp Ordering: Eq, Ord, Show #

How two values compare.

Cases
  • case LessThe first comes before the second.
  • case EqualNeither comes first.
  • case GreaterThe first comes after the second.
fun reverse(self) -> Ordering #

Less becomes Greater and the other way round.

fun then(self, other: Ordering) -> Ordering #

Breaks a tie: a.age.cmp(b.age).then(a.name.cmp(b.name)).

warp Reverse[T: Ord]: Ord #

A value that compares the other way round: sorting by Reverse(score) puts the highest score first.

Fields
  • pub value: TThe value being compared the other way round.
fun lt(self, other: Reverse[T]) -> bool #

Whether this comes first: when the wrapped value comes after other's.

Functions

fun cmp[T: Ord](a: T, b: T) -> Ordering #

How a compares to b: x.cmp(y) also works on numbers and text.

fun min[T: Ord](a: T, b: T) -> T #

The smaller of two values (the first, if they are equal).

fun max[T: Ord](a: T, b: T) -> T #

The larger of two values (the first, if they are equal).

fun clamp[T: Ord](x: T, lo: T, hi: T) -> T #

x, or the nearest of lo and hi when it is outside them.
