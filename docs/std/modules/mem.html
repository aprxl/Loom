std / mem

std.mem

Memory: spools (the places values are allocated in), sizes, and moving values around. heap is the global spool, where ^e boxes a value. An Arena hands out memory by bumping a pointer and frees it all at once; a Pool[T] recycles slots of one type. A pointer into a spool can't outlive it: the region checker sees to that.

mem_example.looman example to run
use std.io.print
use std.mem.Arena

warp Tree {
    case Leaf(i64)
    case Node(^Tree, ^Tree)
}

fun sum(t: ^Tree) -> i64 = match t^ {
    .Leaf(n) => n
    .Node(l, r) => sum(l) + sum(r)
}

fun main() {
    spool frame = Arena(4096)
    // Each `put` is a bump of a pointer; the whole arena is freed at once.
    let leaf = (n: i64) => frame.put(Tree.Leaf(n))
    let t = frame.put(Tree.Node(leaf(1), frame.put(Tree.Node(leaf(2), leaf(3)))))
    print("sum {sum(t)}")
}

Types

weft Spool #

A region to allocate in. heap is the global one.

warp Heap: Spool builtin #

The global spool: each allocation is freed when its owner is dropped.

warp Arena: Spool builtin #

A spool that allocates by bumping a pointer and frees everything at once.

fun reset(mut self) #

Frees everything allocated so far.

fun put[T](self, take value: T) -> ^T@self #

Moves value into the arena and gives a pointer to it. The pointer is Copy and owns nothing: it lasts until the arena is reset or ends.

warp SharedArena: Spool builtin #

An Arena that threads may allocate in: its pointers can cross threads, and allocating takes the VM's lock.

fun reset(mut self) #

Frees everything allocated so far.

fun put[T](self, take value: T) -> ^T@self #

Moves value into the arena and gives a pointer to it.

warp Pool[T]: Spool builtin #

A spool of n slots, each one T: allocating and freeing a slot is a few instructions, and a freed slot is the next one given out. It holds plain data (no text, lists or boxes), because dropping the pool does not drop what is still in it.

fun put(self, take value: T) -> ^T@self #

Moves value into a free slot and gives a pointer to it. The pool being full unravels.

fun free(self, p: ^T@self) #

Gives the slot back. The pointer, and any copy of it, must not be used again.

fun reset(mut self) #

Frees every slot.
