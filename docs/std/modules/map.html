std / map

std.map

Hash maps: Map[K, V] from any Hash key to a value. A map remembers the order its keys were first added, so going through it, printing it and comparing two of them all follow that order.

source: runtime/std/map.loomread about it in the book →
map_example.looman example to run
use std.io.print

fun main() {
    var counts: Map[String, usize] = [:]
    for word in "the cat and the hat and the bat".words() {
        counts.entry(word.to_string(), default: 0) += 1
    }
    print(counts)
    print("the: {counts["the"]}, dog: {counts.get("dog"):?}")
    for (word, n) in counts.pairs().sorted_by(_.1 > _.1).take(2) {
        print("{word} x{n}")
    }
}

Types

warp Map[K, V] builtin #

A map from K to V that remembers insertion order: going through it, and showing it, follow the order keys were first added. Build one with Map(), or a literal where a map is expected: let ages: Map[str, u8] = ["ada": 36, "alan": 41] ([:] is empty).

m[k] is the value for k, and unravels when there's none (m.get(k) gives an optional); m[k] = v adds or replaces it. for (k, v) in m goes through the pairs, and a map has the methods of Stream too, over its pairs. Keys must be Hash.

How many keys there are.

Whether there are no keys.

fun get(self, key: K) -> ?V where K: Hash #

A copy of the value for key (m[key] is the value itself).

fun has(self, key: K) -> bool where K: Hash #

Whether there's a value for key.

fun insert(mut self, take key: K, take value: V) -> ?V where K: Hash #

Adds value for key, and gives back the value it replaces.

fun entry(mut self, take key: K, take default: V) ~> mut V where K: Hash #

The value for key as a place to change, for the statement it's in: counts.entry(word, default: 0) += 1. When there's none, default is added first (and key kept); when there is, both are dropped.

fun remove(mut self, key: K) -> ?V where K: Hash #

Takes out the value for key; later keys keep their order.

Removes every key.

The values, in the order of their keys.

A deep copy.

A copy of the oldest entry: the one whose key was added first.

fun last(self) -> ?(K, V) #

A copy of the newest entry: the one whose key was added last.

fun of(pairs: [(K, V)]) -> Map[K, V] where K: Hash #

A map of pairs; a key that comes up again keeps the last value.

fun get_or(self, key: K, default: V) -> V where K: Hash #

The value for key, or default when there is none.

fun retain(mut self, keep: (K, V) => bool) where K: Hash #

Keeps the entries keep says yes to.

fun extend(mut self, take pairs: Stream[(K, V)]) where K: Hash #

Adds each pair; a key already there gets the new value.

fun remove_entry(mut self, take key: K) -> ?(K, V) where K: Hash #

Takes out the entry for key and gives it back with the key you gave.

fun update(mut self, take key: K, f: V => V) where K: Hash #

Replaces the value for key with f of it, if there is one.

fun merge(mut self, take other: Map[K, V], f: (V, V) => V) where K: Hash #

Adds the entries of other; for a key in both, f(mine, theirs).
