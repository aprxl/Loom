std / option

std.option

Optional values: ?T is either some(x) or none. x? passes a none up to the caller, x mend fallback gives a fallback instead, and these methods transform one without unwrapping it.

source: runtime/std/option.loomread about it in the book →
option_example.looman example to run
use std.io.print

fun first_even(xs: [i32]) -> ?i32 = xs.find(_ % 2 == 0)

fun main() {
    let a = first_even([3, 8, 5])
    let b = first_even([1, 3])
    print("{a:?} {b:?}")
    print(a.map(_ * 10) mend 0)
    print(b.map(_ * 10) mend 0)
    print("{a.is_some()} {b.ok_or("no even number"):?}")
}
