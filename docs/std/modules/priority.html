std / priority

std.priority

Priority queues: PriorityQueue[T] always gives back its largest item first. Wrap items in Reverse (from std.cmp) for the smallest first.

source: runtime/std/priority.loomread about it in the book →
priority_example.looman example to run
use std.io.print
use std.priority.PriorityQueue
use std.cmp.Reverse

fun main() {
    var jobs: PriorityQueue[(u8, String)] = PriorityQueue.new()
    jobs.push((2, "dye the yarn"))
    jobs.push((9, "fix the loom"))
    jobs.push((5, "wind the bobbin"))
    while jobs.pop() is some((urgency, job)) {
        print("{urgency}: {job}")
    }
    var smallest = PriorityQueue.from_list([Reverse(7), Reverse(3), Reverse(5)])
    print("smallest first: {smallest.pop().map(_.value):?}")
}

Types

warp PriorityQueue[T: Ord] #

A queue that gives the largest item first. For the smallest first, put Reverse around the items (std.cmp.Reverse). A binary heap in a list: push and pop take O(log n), peek takes constant time.
