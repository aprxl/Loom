std / rand

std.rand

Pseudo-random numbers.

Types

warp Rng

A deterministic xoshiro256** generator: the same seed always gives the same numbers, on every machine. Not for secrets.

fn seeded(seed: u64) -> Rng

A generator that always produces the same sequence for seed.

fn from_entropy() -> Rng

A generator seeded from the clock and the process, so each run gets its own numbers. Not for secrets.

fn next_u64(mut self) -> u64

The next 64 random bits.

fn byte(mut self) -> u8

A random byte: the top 8 bits of next_u64.

fn below(mut self, n: u64) -> u64

A number from 0 up to but not including n, every one equally likely. Unravels if n is 0.

fn between(mut self, lo: i64, hi: i64) -> i64

A number from lo to hi, both included. Unravels if hi < lo.

fn float(mut self) -> f64

A number from 0 up to but not including 1, with 53 random bits.

fn chance(mut self, p: f64) -> bool

true with probability p.

fn shuffle[T](mut self, mut xs: [T])

Puts the items in a random order.

fn choose[T](mut self, xs: [T]) -> ?T

A copy of a random item, if there are any.

fn fill(mut self, mut buf: [u8])

Fills buf with random bytes.

fn jump(mut self) -> Rng

A generator at the current state, which this one then leaves 2^128 steps behind: each call gives a stream that overlaps no other, so every thread can have its own.
