std / num

std.num

Numbers: the methods of every integer and float type (n.pow(2), x.sqrt(), a.gcd(b)...), parsing text into numbers, and the Num weft for code that works on any number. Integers come in every width from 1 to 64 bits (u12, i24), and each operator says what happens on overflow.

source: runtime/std/num.loomread about it in the book →
num_example.looman example to run
use std.io.print

fun main() {
    let n: u32 = 40
    print("{n.pow(2)} {n.count_ones()} {n.trailing_zeros()} {n.to_string_radix(2)}")
    print("{(-7).rem_euclid(3)} {12.gcd(18)} {255.to_string_radix(16)}")
    let x = 2.0
    print("{x.sqrt():.4} {x.pow(10.0)} {(1.0).atan2(1.0) * 4.0}")
    print("{"300".parse[u8]():?} {"-12".parse[i8]():?} {"2.5e3".parse[f64]():?}")
}

warp NumError: Error #

Why text didn't parse as a number.

Cases
  • case EmptyThere was no text to parse.
  • case InvalidThe text isn't a number of that type: a stray character, a sign an unsigned type can't take.
  • case OverflowThe number is too big (or too small) for the type.

Whether it's 2 to the power of something: one bit is one, and it's above zero.

The bits moved n places towards the top; those pushed out come back in at the bottom. n counts modulo the type's width.

The bits moved n places towards the bottom; those pushed out come back in at the top. n counts modulo the type's width.

The greatest number that divides both.
