std / sync

std.sync

Sharing between threads.

Types

warp Atomic[T] builtin

A value that threads can read and update without locks. T is an integer of 8, 16, 32 or 64 bits (usize, isize too), or bool. Every operation is sequentially consistent, and they all take self to read, so threads share one the way they share any other value. With one worker thread runs until it waits, so a loop that spins on load() never lets another thread run: call sched_yield() in it.

fun load(self) -> T

The value now.

fun store(self, value: T)

Sets the value.

fun swap(self, value: T) -> T

Sets the value, and gives the one it replaced.

fun compare_exchange(self, expected: T, desired: T) -> (bool, T)

Sets the value to desired if it's expected. Gives whether it did, and the value that was there.

fun add(self, n: T) -> T where T: Integer

Adds n, and gives the value before. Unravels if the sum doesn't fit, leaving the value as it was.

fun sub(self, n: T) -> T where T: Integer

Subtracts n, and gives the value before. Unravels if the result doesn't fit, leaving the value as it was.

warp Mutex[T] builtin

A value that one thread at a time can lock and use.

fun lock(self) ~> mut T

The value, for the statement it's in: the lock is taken where lock() is evaluated (waiting, in turn, while another thread has it) and given back when the statement ends, however it ends. total.lock() += n changes it. A thread that locks a mutex it has locked already unravels.

warp Spun[T] builtin

A thread started in a loom block: what thread e gives. It's Copy unless its result is once. A thread nobody joined is joined where the block ends.

fun join(take self) -> T

Waits for the thread and gives its result. If a thread of the block unravelled, this unravels with its message instead. A thread is joined once: a second join unravels.

warp Pipe[T] builtin

A bounded queue: threads send items into it and receive them from it, in order. It holds capacity items at most (made with Pipe[T](capacity), which is at least 1). Every method takes self to read, so threads share one. A pipe nobody will fill, with a thread waiting to receive from it, is a deadlock.

fun send(self, take item: T)

Puts item in, waiting while the pipe is full. Unravels if it's closed (before or while it waits).

fun recv(self) -> ?T

Takes the oldest item, waiting while the pipe is empty. none once it's closed and there's nothing left.

fun close(self)

Closes the pipe: what's in it can still be received, nothing more can be sent, and the threads that wait on it wake. Closing it again does nothing.

warp Crew

How many workers may run a loom's threads at once: loom(given: Crew(workers: 2)) { … }. A thread that waits holds no worker. Unravels at the loom if workers is 0.

  • pub workers: usize

Functions

fun sched_yield() extern

Lets the other threads that can run go first: the running thread goes to the back of the queue.
