std / list

std.list

Growable arrays: List[T] owns its elements and grows as you push. It has every method of a slice (std.slice) and of Stream too, so xs.sort(), xs.contains(x) and xs.filter(f) all work on a list.

source: runtime/std/list.loomread about it in the book →
list_example.looman example to run
use std.io.print

fun main() {
    var xs: List[i32] = [5, 3, 8]
    xs.push(1)
    xs.insert(0, 9)
    xs.sort()
    print("{xs} has {xs.len()} items, the largest is {xs.last():?}")
    xs.retain(_ % 2 == 1)
    print("odd ones: {xs}")
}

Types

warp List[T] builtin #

A growable array of T. Build one with List(), List.filled(x, n), or a literal where a list is expected: let xs: List[i32] = [1, 2, 3]. It has every method of a slice ([T]), too.

fun filled(x: T, n: usize) -> List[T] #

n copies of x.

fun push(mut self, take x: T) #

Adds x at the end.

fun pop(mut self) -> ?T #

Takes the last element off, if there is one.

fun insert(mut self, i: usize, take x: T) #

Puts x at index i, moving the rest up. Unravels if i > len.

fun remove(mut self, i: usize) -> T #

Takes out the element at i, moving the rest down. Unravels if i >= len.

fun clear(mut self) #

Removes every element.

fun truncate(mut self, n: usize) #

Keeps the first n elements.

fun extend(mut self, take items: Stream[T]) #

Adds each of the items at the end.

fun copy(self) -> List[T] #

A deep copy: a new list with a copy of every element.

fun retain(mut self, keep: T => bool) #

Keeps the elements keep says yes to, in their order.

fun dedup_by_key[K: Eq](mut self, key: T => K) #

Removes each element whose key equals the key of the one before it: words.dedup_by_key(_.len()) keeps the first word of each run of equal lengths.

fun dedup(mut self) where T: Eq #

Removes each element that equals the one before it.

fun swap_remove(mut self, i: usize) -> T #

Takes out the element at i by moving the last one into its place: quick, but it changes the order. Unravels if i >= len.

fun resize(mut self, n: usize, x: T) #

Grows with copies of x, or shrinks, to n elements.

fun split_off(mut self, at: usize) -> List[T] #

Cuts the list at at: this keeps the first at elements, and the rest are returned. Unravels if at > len.

fun append(mut self, mut other: List[T]) #

Moves every element of other to the end of this list.

fun drain(mut self, from: usize, to: usize) -> List[T] #

Takes out the elements in from..to and returns them. Unravels if the range is outside the list.
