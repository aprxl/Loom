std / list

std.list

Growable arrays.

Types

warp List[T] builtin

A growable array of T. Build one with List(), List.filled(x, n), or a literal where a list is expected: let xs: List[i32] = [1, 2, 3]. It has every method of a slice ([T]), too.

fn filled(x: T, n: usize) -> List[T]

n copies of x.

fn push(mut self, take x: T)

Adds x at the end.

fn pop(mut self) -> ?T

Takes the last element off, if there is one.

fn insert(mut self, i: usize, take x: T)

Puts x at index i, moving the rest up. Unravels if i > len.

fn remove(mut self, i: usize) -> T

Takes out the element at i, moving the rest down. Unravels if i >= len.

fn clear(mut self)

Removes every element.

fn truncate(mut self, n: usize)

Keeps the first n elements.

fn extend(mut self, take items: Stream[T])

Adds each of the items at the end.

fn copy(self) -> List[T]

A deep copy.

fn retain(mut self, keep: T => bool)

Keeps the elements keep says yes to, in their order.

fn dedup_by_key[K: Eq](mut self, key: T => K)

Removes the elements same_key of which equals the one before's.

fn dedup(mut self) where T: Eq

Removes each element that equals the one before it.

fn swap_remove(mut self, i: usize) -> T

Takes out the element at i by moving the last one into its place: quick, but it changes the order. Unravels if i >= len.

fn resize(mut self, n: usize, x: T)

Grows with copies of x, or shrinks, to n elements.

fn split_off(mut self, at: usize) -> List[T]

Cuts the list at at: this keeps the first at elements, and the rest are returned. Unravels if at > len.

fn append(mut self, mut other: List[T])

Moves every element of other to the end of this list.

fn drain(mut self, from: usize, to: usize) -> List[T]

Takes out the elements in from..to and returns them. Unravels if the range is outside the list.
