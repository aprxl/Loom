std / fs

std.fs

Files: read and write whole files as text or bytes, append lines, look at metadata, and walk directories. Every function that can fail returns T ! IoError.

source: runtime/std/fs.loom

In a sandboxed run (the docs' playground, the test fixtures) the files are in memory and start out empty, so a program can write a file and read it back, as this one does.

fs_example.looman example to run
use std.io.print
use std.fs

fun main() ! fs.IoError {
    fs.write_text("notes.txt", "warp\nweft\n")?
    let text = fs.read_text("notes.txt")?
    print("{text.lines().count()} lines, {fs.file_size("notes.txt")} bytes")
    print("{fs.read_text("missing.txt"):?}")
}
