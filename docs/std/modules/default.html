std / default

std.default

Values with a default.

Types

weft Default

Types that have a value to start from: 0, false, empty text, an empty list. A warp that lists Default in its header and doesn't write default gets one: each field takes its own default if it has one, and its type's otherwise. A warp with cases takes its first, if it carries nothing.

warp Config: Default {
    host: String = "localhost"
    port: u16
}
// Config.default() is Config(host: "localhost", port: 0)
