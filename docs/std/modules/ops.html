std / ops

std.ops

The wefts behind operators and value semantics: Eq (==), Ord (< and friends), Hash (map keys and set elements) and Copy (values that are copied instead of moved).

source: runtime/std/ops.loomread about it in the book →

A warp that lists Eq, Ord or Hash in its header without writing the method gets one that works field by field: see "Deriving" in the Warps, wefts and weaves chapter.

Types

weft Copy #

Values that are copied rather than moved.

weft Eq #

== and !=.

fun eq(self, other: Self) -> bool builtin #

Whether the values are equal. Derived: every field is equal, and for a warp with cases, it's the same case.

weft Ord: Eq #

<, <=, >, >=.

fun lt(self, other: Self) -> bool builtin #

Whether self comes first. Derived: fields compare in order, the first that differs decides, and earlier cases come first.

weft Hash #

Values that can be map keys and set elements. A warp that lists Hash in its header without writing hash gets one that combines its fields' hashes. Two values that are == must hash the same.

fun hash(self) -> u64 builtin #

A number that is the same for equal values. It may change between versions of Loom: for a hash to write down, see std.hash.fnv1a.

weft Integer: Ord, Copy, Show builtin #

Every integer type, u1 through i128.
