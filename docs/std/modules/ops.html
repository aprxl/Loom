std / ops

std.ops

The wefts behind operators and value semantics. A warp that lists Eq, Ord or Hash in its header without writing the method gets one that works field by field (see 02-types, "Deriving").

Types

weft Copy

Values that are copied rather than moved.

weft Eq

== and !=.

fn eq(self, other: Self) -> bool builtin

Whether the values are equal. Derived: every field is equal, and for a warp with cases, it's the same case.

weft Ord: Eq

<, <=, >, >=.

fn lt(self, other: Self) -> bool builtin

Whether self comes first. Derived: fields compare in order, the first that differs decides, and earlier cases come first.
