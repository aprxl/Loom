std / deque

std.deque

Double-ended queues: Deque is a list you can push to and pop from at both ends, each in constant time (on average). Reach for it when a List would keep inserting at the front.

source: runtime/std/deque.loomread about it in the book →
deque_example.looman example to run
use std.io.print
use std.deque.Deque

fun main() {
    var q = Deque[String].new()
    q.push_back("weft")
    q.push_back("weave")
    q.push_front("warp")
    print(q.to_list())
    print("{q.pop_front():?} then {q.pop_back():?}, {q.len()} left")
}

warp Deque[T] #

A queue with fast pushes and pops at both ends. Two stacks, so every operation takes constant time except the occasional one that moves half the items from one side to the other; any run of n operations costs O(n).
