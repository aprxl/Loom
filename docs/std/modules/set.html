std / set

std.set

Hash sets: Set[T] holds each Hash value at most once, remembers the order values were added, and has the usual set algebra.

source: runtime/std/set.loomread about it in the book →
set_example.looman example to run
use std.io.print

fun main() {
    let warm = Set.of(["madder", "weld", "saffron"])
    let bright = Set.of(["weld", "woad", "saffron"])
    print(warm.intersection(bright))
    print(warm.union(bright).sorted())
    print("woad is warm: {warm.has("woad")}")
}

warp Set[T] builtin #

A set of T that remembers insertion order. Build one with Set() or Set.of(xs). for x in s goes through it in order, and a set has the methods of Stream too. Its elements must be Hash.
