std / error

std.error

Errors and giving up. A function that can fail returns T ! E; the ? operator passes an error up, mend handles it, and fail produces one. Any warp that weaves Error can be an error, and unravel gives up on the whole thread (as a panic does elsewhere), running defers on the way out.

error_example.looman example to run
use std.io.print

warp ConfigError: Error {
    case Missing(key: String)
    case Bad(key: String, value: String)
}

fun port(text: str) -> u16 ! ConfigError {
    let (key, value) = text.split_once("=") mend fail .Missing(key: text.to_string())
    value.trim().parse[u16]() mend fail .Bad(key: key.to_string(), value: value.to_string())
}

fun main() {
    print("{port("port=8080"):?}")
    print("{port("port=lots"):?}")
    print("{port("nothing"):?}")
    let p = port("port=99") mend e => {
        print("gave up: {e.message()}")
        0
    }
    print(p)
}

fun unravel(message: str) -> never host #

Gives up: unwinds the current thread, running defers on the way out.

fun assert(condition: bool, message: str = "assertion failed") host #

Unravels with message unless condition holds. In a const context, a failed assertion is a compile error.
