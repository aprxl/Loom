std / slice

std.slice

Slices: views of contiguous elements.

Types

warp Slice[T] builtin

[T]: a view of contiguous Ts, in an array or a list. Arrays and lists have these methods too.

fn len(self) -> usize

How many elements there are.

fn get(self, i: usize) -> ?T

A copy of the element at i, or none past the end. (An element can't be moved out of a slice: it gives a value of its own, a deep copy for a type that isn't Copy.)

fn first(self) -> ?T

A copy of the first element.

fn last(self) -> ?T

A copy of the last element.

fn contains(self, x: T) -> bool where T: Eq

Whether some element equals x.

fn index_of(self, x: T) -> ?usize where T: Eq

The index of the first element equal to x.

fn copy_from(mut self, src: [T])

Copies src over the start of this slice. Unravels if src is longer.

fn fill(mut self, x: T)

Sets every element to a copy of x.

fn sort(mut self) where T: Ord

Sorts in order, keeping equal elements in the order they were in.

fn to_list(self) -> List[T]

A new list with a copy of every element.

fn map[U](self, f: T => U) -> List[U]

A new list of f of each element. (xs.indexed() and the other methods of Stream work on slices too, lazily.)

fn filter(self, f: T => bool) -> List[T]

A new list with a copy of each element f says yes to.

fn chunks(self, n: usize) -> Stream[[T]]

Views of n elements at a time, one after another; the last may be shorter. Unravels if n is 0.

fn chunks_mut(mut self, n: usize) -> Stream[[T]]

Views of n elements at a time, one after another, which can be changed (line[i] = x). They don't overlap, so in a loom for each thread may change its own piece. The last may be shorter. Unravels if n is 0.

fn windows(self, n: usize) -> Stream[[T]]

Views of every run of n elements in a row: [a, b], [b, c], … Unravels if n is 0.

fn starts_with(self, prefix: [T]) -> bool where T: Eq

Whether the slice starts with prefix.

fn ends_with(self, suffix: [T]) -> bool where T: Eq

Whether the slice ends with suffix.

fn count_of(self, x: T) -> usize where T: Eq

How many elements equal x.

fn rotate_left(mut self, n: usize)

Moves the elements n places towards the start; those pushed out come back at the end. n counts modulo the length.

fn rotate_right(mut self, n: usize)

Moves the elements n places towards the end; those pushed out come back at the start. n counts modulo the length.

fn rev(self) -> Stream[T]

The elements from the last to the first.

fn sort_by(mut self, less: (T, T) => bool)

Sorts so that less(a, b) says whether a goes before b. Stable: elements neither goes before the other keep their order.

fn sort_by_key[K: Ord](mut self, key: T => K)

Sorts by key of each element, which is computed once per element. Stable.

fn is_sorted(self) -> bool where T: Ord

Whether every element is at or after the one before it.

fn lower_bound(self, x: T) -> usize where T: Ord

The index of the first element that is not before x in a sorted slice: where x would go.

fn upper_bound(self, x: T) -> usize where T: Ord

The index of the first element after x in a sorted slice.

fn binary_search(self, x: T) -> ?usize where T: Ord

The index of an element equal to x in a sorted slice.

fn partition_point(self, pred: T => bool) -> usize

In a slice where pred says yes to a run of elements and then no to the rest, the index of the first no.
