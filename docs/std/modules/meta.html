std / meta

std.meta

Reflection: what compile-time code can learn about a type. T.name, T.kind, T.fields and T.cases are known while compiling, and so is everything read from them; none of it is left in the program.

warp Field: Copy builtin

A field of a record, or of a case's payload: an item of T.fields or c.fields. It has a name: str, is_pub: bool and offset: usize (where it starts in the value, in bytes), and v.(f) is v's field f. Only compile-time code has one.

warp Case: Copy builtin

A case of a sum: an item of T.cases. It has a name: str and fields, and v is .(c) tests whether v is case c. Only compile-time code has one.
