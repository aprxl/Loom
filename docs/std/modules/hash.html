std / hash

std.hash

Hashes that stay the same between versions and machines.

Functions

fun fnv1a(bytes: [u8]) -> u64

The FNV-1a hash of bytes: the same on every machine and in every version, unlike Hash.hash, which can change.

fun combine(a: u64, b: u64) -> u64

A hash of the two hashes together, which depends on their order.
